# 玩家 POV 雷达实现设计

状态：已停止执行。2026-10-07 用户改为官方方形 Demo 雷达，并选择 A 接受原生双方位置显示。以下保留为实验历史，不作为当前交付标准；当前要求见 PRD.md 的 A23 用户变更。

## 目标

补完 HUD 页的雷达开关，显示接近所选玩家实战视角的雷达。沿用现有五页导航、单片段录制和安全恢复，不引入另一套 HUD 模式。默认隐藏，开关保存在 HUD 预设并冻结到录制任务。

## 已核实事实

- 当前真实 Demo 可读取位置、朝向、存活状态、同 tick 阵营、spotted 和 approximate_spotted_by。
- 8Hz 采样共 151990 条玩家记录，发现状态记录 7610 条；发现者稳定身份都能在同 tick 对应到玩家，两阵营均有记录。
- 原始 Demo SHA256 未变化，未复制 Demo、未启动游戏、未修改游戏文件。
- 已只读取得安装游戏的 Mirage 与 Dust2 overview 坐标配置，以及 Mirage 地图纹理资源路径。Dust2 配置存在不代表第二地图 Demo 或实机验收已经通过。
- 原有样式试验只能证明圆形外观，原生 Demo 雷达显示双方全图位置，不符合 POV 信息要求。

## 推荐方案

复用本机 CS2 的地图背景资源，以本项目自己的 Panorama 脚本绘制 POV 标记。安装包不再增加来源待核实的第三方编译雷达样式，也不复制或分发整套地图素材。

数据从原 Demo 的片段区间和必要的前序历史提取，独立缓存，不让不用雷达的录制承担额外解析。位置与地图配置来自本机已有资料，按 Demo 内容、地图、游戏版本和资源哈希绑定。

- 自己与队友：按照稳定身份、当时阵营、存活状态绘制；外观默认沿用本机当前 CS2 雷达设置，包括缩放、旋转、居中及 HUD 大小；不强制固定圆形或旋转。
- 敌人：只在发现者属于所选玩家当前阵营且字段有效时显示。失去发现后只能保留此前已知位置，不能继续读取敌人的隐藏移动来更新标记。
- 暂停、跳转、加速和切换玩家：以游戏实际回放 tick 重建状态，不用墙钟推进，不沿用另一玩家或未来 tick 的敌情。
- 阵营变化、死亡、断线和数据缺失：清理过时状态；身份或数据无法验证时阻断显示，不推测敌情。
- 雷达关闭：不解析轨迹、不部署雷达数据，保持原来隐藏模式。

## 沿用游戏内雷达设置

根据用户补充，优先同步本机当前游戏设置，不要求用户在应用里重复配置地图缩放、旋转、居中及雷达/HUD 大小。地图背景使用当前安装游戏的对应地图资源，避免自带旧截图。

读取本次本地回放实际生效的允许参数，配置文件只作为读取来源之一；不能仅凭字段名猜测或把缺失值当成默认值。跟随本机所选账户的设置，不声称可以恢复 Demo 原玩家录制当时的个人设置。

原生 Demo 雷达包含观战信息，故外观跟随设置，标记内容仍按所选玩家和当时发现记录筛选。平方/圆形、地图分层、雷达图标大小等参数逐项验证，未验证的不承诺完全同步。正常录制无需新增同步按钮，任务开始时自动读取并冻结；任务后保留原设置。

## 渲染与资源边界

2026-10-07 实机补充确认：用户选择沿用正常打游戏的雷达外观。本次回放临时设置 `cl_radar_square_when_spectating 0`，其他雷达外观参数沿用游戏实际设置；受管理会话退出后恢复配置原字节。此命令须在显示/冻结设置前发送，不能把正常方形偏好 `cl_radar_square_always` 强制改为圆形。

显示背景、所选玩家方向、队友与有效敌人标记，优先核对旋转、缩放、地图位置、遮罩和原游戏观感。其他实战元素的还原程度须记录，不能声称像素级完全一致。

只读取游戏 VPK 目录索引和指定 overview 小文件，不复制大型 VPK。新脚本与轨迹通过会话资源构建器加入，严格验证输入、会话身份、资源大小和重建结果；不破坏现有固定基包哈希及备份恢复。

解析器将发现者字段称为 approximate，因而字段存在并不足以证明与客户端行为完全一致，必须用实际回放核对。插值不得把敌人未来位置或未发现位置泄漏到当前画面。

## 分阶段实施及测试

1. 数据与地图读取：开发严格的轨迹读取、稳定身份与即时阵营映射、overview 小文件读取；测试缺失字段、未知身份、半场换边、损坏配置、原 Demo 只读和坐标变换；核验游戏设置读取、任务快照与不改写原设置。
2. 信息规则与绘制：实现可重复的 tick 查询、发现/失去视野、最后已知位置和 Panorama 渲染；测试未来数据泄漏、隐藏敌人移动、暂停、跳转、加速、死亡和玩家切换。
3. 会话与设置：预设迁移默认 false，快照冻结，业务门控，资源构建及录制链路接入；测试伪造 true、旧预设保留、关闭雷达、版本失效及异常恢复。
4. 实机专项：两地图 × CT/T，覆盖 A23 要求的移动、发现、失去视野、死亡、显示/隐藏；退出后核对恢复。缺少第二 Demo 或无法操作游戏时明确请求必要配合，不用模拟测试冒充实机通过。
5. 完整回归与交付：所有测试通过后生成新的独立包；不覆盖现有 v2026.10.07 成品，专项证据通过后才开放显示选项并更新验收文档。

每阶段先运行对应有效测试，失败定位修复后继续；不删除、不跳过测试，不降低 A23 门槛。尚未通过的游戏/地图组合不开放显示资格。
