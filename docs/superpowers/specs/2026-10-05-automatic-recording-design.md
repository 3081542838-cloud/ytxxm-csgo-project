# 正常录制自动化补充设计

日期：2026-10-05。依据使用者最新指示：正常录制由应用自动判断与执行，确实需要使用者操作或选择时才停下询问。此指示更新旧 PRD 的逐次人工确认要求；安全和实际验收门槛保留。

## 目标与边界

选择 Demo、玩家、片段和 HUD 后，正常任务从准备、开始、播放、停止至恢复连续执行。首次环境设置、异常状态和发布实机验收可以需要使用者参与；不把人工确认转成定时器自动点击，也不靠聊天助手日常读截图。

保留单任务、原 Demo 只读、小文件事务、受管理 `-insecure` 身份、真实双 tick/玩家回读、10,000,000,000 字节磁盘门槛、一次输入先持久化、未知状态不重试、独立视频及恢复结果。每端最多两秒不变，不增加自动裁剪、OBS、自行 NVENC 编码或匹配功能。

## 一、控制台提交通路

先验证当前 CS2 的 `-concommandpipe`。本机 engine2.dll 有 `CConsoleCommandPipes::Create` 和 `-concommandpipe requires -insecure`，SHA256 为 `d51f38d013adc2e97448116e0fe3bddb31cf2340a18c353d3ce46aaba520d712`。协议依据固定版本 [Hammer5Tools 实现](https://github.com/dertwist/Hammer5Tools/blob/d7487f751826f47cfd618b598bd8985e21694efb/Hammer5ToolsGUI/gui/other/cs2_netcon.py)，必须进行本机验证。

应用先创建本会话随机命名的两条 Windows 命名管道，然后才启动 CS2。限制单实例、本用户 ACL、拒绝远程连接，两个 client PID 必须均属于同一持有的 CS2，创建时间和完整 exe 路径也要一致。UTF-8/LF 有界一次写；部分写、断开、期限跨越即失效，不重试。

管道仅替代控制台文字输入，不把传输成功当执行成功。原 `engine.log` 新 nonce、实际查询结果、真实 Demo/目标玩家/精确 tick 回读继续有效。首轮只查询 F8，不加载 Demo、不录制；退出后仍做独立九项恢复审计。通过后才接精确准备及正常回放，旧键盘入口保留为明确的诊断/异常人工方式。

## 二、NVIDIA 状态观察

先做独立只读观察器，核验 Windows UIA 能否从当前 NVIDIA Overlay 的真实进程和可见元素取得明确状态。仅检查所需 NVIDIA 元素，限数量/深度/耗时，阻塞读取放独立 worker，绝不影响 Qt 响应。

证据带来源 exe/PID/创建时间、窗口、版本、采集时刻和序号；主应用、Instant Replay、允许录制设置、旧提示和文字冲突不能证明当前手动录制状态。没有明确状态即 unknown，不从图标缺失、热键成功或文件增长推断 idle。

`CaptureCore.log` 的实际开始/完成回调可以交叉检查，但不是承诺稳定的官方状态 API。只消费本次观察起点后的连续新内容，轮转、截断、组件重启或会话/目标无法关联时失效。初始 idle、开始后的 recording、停止后的 stopped 均须实测来源可用才接入协调器。

## 三、接入现有流程

维持 `PreviewSession → Playback → RecordingTask → 恢复`。自动证据必须绑定当前任务、步骤 token、完整身份和冻结范围，不能作为通用布尔确认。正常 UI 只显示进度和取消；异常才显示当前步骤的人工处理入口。

NVIDIA 首次开始前有新鲜 idle 证据，持久化输入资格后仅发一次热键；看到本次真实 recording 转换后才播放。实际终点暂停后只发一次停止；实际 stopped/保存证据和最终回放检查后进入恢复。没有状态证据、超时、矛盾或取消后迟到结果均不授权新输入。崩溃重启不自动续播或补发热键。

## 执行顺序与可检查结果

1. 管道适配器及启动参数边界 red→green，Windows 管道集成通过。
2. 只查询的受管理实机探测，新 nonce 和准确结果通过，独立九项恢复通过。
3. 自动精确准备/回放接入及故障测试，通过本机起点、玩家、移动和终点核验。
4. NVIDIA 只读状态观察器及旧/错/冲突/超时证据测试；明确三个状态的实机闭环后才启用自动录制。
5. 正式单次自动录制及恢复通过后继续原阶段 8、9、10，不以接口或离线 mock 成功代替实机。
6. 每次产品改动运行相关测试，最终运行完整入口。保留旧安全断言和失败记录，不删除、跳过或降低验收。

自动状态来源未实证时，界面不得宣称全自动可用。硬件、资源许可、雷达 A23 和两机各十次门槛继续独立记录；实在需要外部配合时给使用者一个明确问题和可选择方案。
